# Java foundations and existing practice

This module preserves your existing exercises. Use it for targeted revision, not a required restart of Java basics.

Before timed interviews, be able to explain and demonstrate:

- [ ] Primitive vs reference semantics; overflow; null and bounds checks.
- [ ] Generics, interfaces, composition, records, immutability.
- [ ] `equals`/`hashCode`, comparators, mutable map-key hazards.
- [ ] ArrayList, HashMap, HashSet, ArrayDeque, PriorityQueue and their costs.
- [ ] Exceptions, API contracts, defensive copies and unit tests.
- [ ] Threads, executors, synchronization, visibility and atomic operations.
- [ ] BigDecimal for money; java.time for time; injected clocks for tests.

Do not rewrite every old package just for naming consistency. Add focused examples when a diagnostic exposes a gap. The `java-dsa-practice` module owns new interview algorithms.
