# 2. Store information and do maths

Think of a variable as a labelled box holding a value.

## New words

int: whole number. double: decimal number. boolean: true or false. String: text. = stores a value; == compares values.

## VariablesAndMaths

Store a name, count, price, and yes/no value.

Open [VariablesAndMaths.java](VariablesAndMaths.java). Read these steps alongside the code:

1. Declare each variable with a type and name.
2. Multiply price by quantity.
3. Use + to join text with a value.
4. Whole-number division discards the fractional part. % gives the remainder.

From the `java-zero-to-dsa` folder, run:

```sh
java 02-variables-and-maths/VariablesAndMaths.java
```

Expected output:

```text
Name: Asha
Total: 76.5
Learning: true
7 / 2 = 3
7 % 2 = 1
```

**Try it yourself:** Calculate the total cost of four pens costing 12.5 each.

**Work and memory:** Not needed yet; focus on understanding the steps.
