# 1. Your first Java program

A program is a set of instructions. Here we ask the computer to display a message.

## New words

Java: the language we write in. JDK: the tools that run Java. Output: what the program displays.

## HelloWorld

Display your first message.

Open [HelloWorld.java](HelloWorld.java). Read these steps alongside the code:

1. The class is the container for our program. Its name matches the file name.
2. main is where this program starts.
3. System.out.println displays text and moves to a new line.
4. Quotation marks surround text. A semicolon ends this instruction. Curly braces group instructions.

From the `java-zero-to-dsa` folder, run:

```sh
java 01-hello-world/HelloWorld.java
```

Expected output:

```text
Hello, World!
I am learning Java step by step.
```

**Try it yourself:** Print your name and one reason you want to learn coding.

**Work and memory:** Not needed yet; focus on understanding the steps.
