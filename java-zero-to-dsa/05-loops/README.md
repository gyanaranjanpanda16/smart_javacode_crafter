# 5. Repeat work

A loop repeats instructions, like checking every item on a shopping list.

## New words

for: repeat with a counter. while: repeat while a condition is true. i++: increase i by one.

## LoopsAndSum

Print 1 to 5 and calculate their sum.

Open [LoopsAndSum.java](LoopsAndSum.java). Read these steps alongside the code:

1. Start the counter at 1.
2. Continue while the counter is at most 5.
3. Add the current number to the total, then increase the counter.
4. The while loop counts down until its condition becomes false.

From the `java-zero-to-dsa` folder, run:

```sh
java 05-loops/LoopsAndSum.java
```

Expected output:

```text
1
2
3
4
5
Sum: 15
Countdown: 3
Countdown: 2
Countdown: 1
```

**Try it yourself:** Print the multiplication table of 7. Make sure your loop eventually stops.

**Work and memory:** Not needed yet; focus on understanding the steps.
