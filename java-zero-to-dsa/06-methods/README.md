# 6. Reuse a set of instructions

A method is a small named job, like a recipe you can use repeatedly.

## New words

Parameter: an input to a method. return: sends a result back. void: no returned result. static: call without creating an object.

## MethodsExample

Put addition in a reusable method.

Open [MethodsExample.java](MethodsExample.java). Read these steps alongside the code:

1. add receives two numbers.
2. It returns their sum to the caller.
3. main calls it twice with different inputs.

From the `java-zero-to-dsa` folder, run:

```sh
java 06-methods/MethodsExample.java
```

Expected output:

```text
10
5
```

**Try it yourself:** Write a method that returns the larger of two integers.

**Work and memory:** Not needed yet; focus on understanding the steps.
