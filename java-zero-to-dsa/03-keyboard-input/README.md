# 3. Let the user type

Input is information coming into a program, like your name in a form.

## New words

Scanner: a tool that reads keyboard input. import: lets you use a library class; here we use its full name instead.

## GreetingInput

Read a name and greet the user.

Open [GreetingInput.java](GreetingInput.java). Read these steps alongside the code:

1. Create a Scanner connected to System.in, the keyboard input.
2. nextLine reads one whole line.
3. Type your name and press Enter when asked.

From the `java-zero-to-dsa` folder, run:

```sh
java 03-keyboard-input/GreetingInput.java
```

When prompted, type `Asha` and press Enter. Your typed input is not included in the output below.

Expected output:

```text
What is your name?
Hello, Asha!
```

**Try it yourself:** Ask for a favourite food on a second line and print it.

**Work and memory:** Not needed yet; focus on understanding the steps.
