# 4. Make decisions

An if statement chooses a path, like taking an umbrella if it is raining.

## New words

if: do this when a condition is true. else: otherwise. && means both; || means either; ! means not.

## EvenOdd

Decide whether a number is even.

Open [EvenOdd.java](EvenOdd.java). Read these steps alongside the code:

1. An even number has remainder zero when divided by two.
2. Only one branch runs.
3. Zero and negative even numbers also work.

From the `java-zero-to-dsa` folder, run:

```sh
java 04-decisions/EvenOdd.java
```

Expected output:

```text
Odd
```

**Try it yourself:** Try 0, -4, and 13. Then classify a number as positive, negative, or zero.

**Work and memory:** Not needed yet; focus on understanding the steps.
